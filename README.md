# Client configuration examples

Replace the executable path and `C:\Projects\my-project` with your own. These files contain no credentials; Central Brain's MCP server runs as a local child process and needs no API key.

| File | Client | Where it goes |
|---|---|---|
| `claude_desktop_config.json` | Claude Desktop | Settings > Developer > Edit Config |
| `mcp.json` | Claude Code | `.mcp.json` in the project root |
| `vscode-mcp.json` | GitHub Copilot in VS Code | `.vscode/mcp.json` |
| `codex-config.toml` | ChatGPT desktop app / Codex | `~/.codex/config.toml` |
